Works with Claude 개인정보처리방침

시행일: 2026-10-28

1. 처리하는 정보

  • 사용자가 「Claude 참가」를 누른 NAVER WORKS 메시지방의 메시지 내용, 보낸 사람 이름, 시각, 첨부 파일
  • 내 NAVER WORKS 이름(Claude 가 쓴 글의 [이름_Claude] 머리말에 사용)
  • 방 이름, 방 번호, 방에 초대된 봇 목록(「Claude 협업방 BOT」이 있는지 확인하는 용도)
  • 패널 설정 값(첨부 파일만 읽기 여부, 글 즉시 전송, 파일 즉시 전송 여부, 패널 자동 열기 여부)
  • NAVER WORKS 탭이나 패널을 마지막으로 사용한 시각(클릭, 키 입력, 스크롤이 있었던 시각만 저장하고 무엇을 눌렀는지, 어디를 눌렀는지는 저장하지 않습니다. 사용자가 한동안 쓰지 않을 때 자동 읽기를 쉬는 데만 씁니다)
  • NAVER WORKS 가 요청을 거절했을 때의 호출 멈춤 상태(멈춘 시각과 응답 상태 코드. 계정 보호를 위해 사용자가 「다시 시작」을 누를 때까지 호출을 멈추는 데 씁니다)

참가하지 않은 방의 대화는 저장하지 않습니다. 「Claude 협업방 BOT」이 초대된 방에서만 참가할 수 있습니다.

2. 처리 목적

사용자가 자기 PC 에서 실행한 Claude Code 세션이, 사용자가 허용한 방의 대화와 첨부를 읽고 그 방에 글이나 파일을 올릴 수 있게 하기 위해서만 사용합니다.

3. 저장 위치와 전송

  • 정보는 사용자 PC 의 로컬 폴더(%LOCALAPPDATA%\WorksWithClaude)와 브라우저 저장소에만 저장됩니다.
  • 확장 프로그램과 로컬 브리지는 사용자 PC 안(127.0.0.1)에서만 통신하며, 개발자나 제3자의 서버로 정보를 보내지 않습니다. 로컬 브리지는 다른 웹페이지에서 온 요청을 거절합니다.
  • 사용자가 실행한 Claude Code 세션이 읽은 내용은 그 세션의 AI 서비스(Anthropic Claude) 이용 약관과 개인정보처리방침에 따라 처리됩니다. 이 처리는 사용자의 Claude Code 이용에 해당하며 이 확장이 직접 하는 전송이 아닙니다.
  • 정보를 판매하거나 광고, 신용 평가 등 다른 목적으로 쓰지 않습니다.

4. 보관과 삭제

  • 「참가 회수」를 누르면 그 방의 저장 기록이 즉시 삭제됩니다.
  • 방에서 「Claude 협업방 BOT」이 나가면 참가가 자동 회수되고 기록이 삭제됩니다.
  • 확장을 삭제하고 위 로컬 폴더를 지우면 모든 정보가 삭제됩니다.

Summary (English)

Works with Claude processes message content and attachments only from NAVER WORKS chat rooms the user explicitly joins. Apart from that, it keeps only panel settings, the time of the user's last click, key press or scroll in NAVER WORKS (the time only, never what was pressed or where; used to pause background reading while the user is away), and a paused state recorded when NAVER WORKS rejects requests. All data stays on the user's own computer (local folder and a local server bound to 127.0.0.1). The extension does not send data to the developer or any third-party server, does not sell data, and does not use it for any purpose other than letting the user's own local Claude Code session read and post in those rooms. Leaving a room deletes its stored data immediately.
